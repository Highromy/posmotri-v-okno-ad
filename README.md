# Посмотри в окно

Учебный проект по вёрстке веб-приложения в рамках курса
Яндекс Практикума.

## О проекте

Приложение для просмотра видео из разных городов
с возможностью поиска по городу и времени суток.

## Технологии

- HTML5
- CSS3
- Flexbox
- БЭМ
- JavaScript (предоставлен в заготовке проекта)

## Запуск

Откройте файл `index.html` в браузере.
